# Pencarian cover buku sekolah

Diperbarui 11 Oktober 2026.

## Hasil

- Seluruh 231 judul buku sekolah sudah memiliki cover: 133 hasil pencarian sumber buku dan 98 sampul ilustrasi dari data sekolah.
- Ditambahkan 115 cover buku sekolah, ditambah 1 cover untuk buku manual Hitam. Sebelumnya ada 18 cover buku sekolah.
- Setiap judul tanpa cover ditelusuri melalui pencarian web dan gambar. Kandidat diperiksa secara visual; hasil dengan judul atau penulis berbeda tidak dipakai.
- Berkas cover disimpan lokal di `storage/app/public/covers/school/`. Sumber tiap gambar tercatat di [sumber-cover-sekolah.json](sumber-cover-sekolah.json).
- Pemeriksaan: 116 gambar baru valid; jumlah buku tetap 237 termasuk arsip, judul tidak berubah. Pemeriksaan HTTP dan pratinjau katalog dilakukan secara lokal.

## Batas kecocokan

Sebagian buku lama memiliki beberapa desain sampul. Pencocokan menggunakan judul, penulis, dan keterangan sumber yang tersedia; edisi fisik sekolah belum dapat dipastikan tanpa ISBN atau foto sampul. Beberapa cover berupa foto buku karena gambar penerbit tidak ditemukan.

Data sekolah juga mengandung perbedaan identitas. Contohnya Shades of Earth tertulis Beth Hoffman (sumber cover Beth Revis), The Naked Traveler tertulis Bondan Winarno (sumber cover Trinity), dan Suara Dilan tertulis Ridi Boriq (sumber cover Pidi Baiq). Judul dan penulis dari impor tetap dipertahankan untuk diperiksa petugas.
